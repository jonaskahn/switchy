# Build Assets

This directory contains all build-time assets and configuration for Switchy.

## Directory Layout

```
build/
├── appicon.svg          # Source icon — edit this; regenerate appicon.png and icon.ico from it
├── appicon.png          # 1024×1024 raster icon consumed by Wails during build
├── bin/                 # Compiled output (gitignored)
│   ├── switchy.exe
│   └── Switchy_Installer.exe
└── windows/
    ├── icon.ico                    # Multi-resolution Windows icon
    ├── info.json                   # Product metadata (version, company, copyright)
    ├── wails.exe.manifest          # UAC / DPI / compatibility manifest
    └── installer/
        ├── installer.iss           # Inno Setup 6 script (primary installer)
        └── project.nsi             # NSIS script (used by wails build --nsis)
```

## Regenerating Icons

If you update `appicon.svg`, regenerate the raster assets before building:

```powershell
# Requires Inkscape or any SVG → PNG converter
inkscape appicon.svg --export-png=appicon.png --export-width=1024

# Requires ImageMagick or similar for .ico
magick appicon.png -define icon:auto-resize=256,128,64,48,32,16 windows/icon.ico
```

Wails will embed `appicon.png` into the binary automatically on the next build.

## Product Metadata

Edit `windows/info.json` to update the version number, company name, or copyright that appears in:
- `switchy.exe` → Properties → Details tab
- The Inno Setup installer header

## Installer (Inno Setup)

`installer/installer.iss` is the primary release installer. It is invoked automatically by `scripts/build.ps1`. Features:
- Admin privileges required
- Optional desktop shortcut
- Optional auto-register as default browser (opens Windows Default Apps)
- Optional fresh-start (wipes `%APPDATA%\Switchy` on install)
- Uninstall optionally removes user configuration

Build the installer standalone (requires [Inno Setup 6](https://jrsoftware.org/isinfo.php)):

```powershell
iscc build\windows\installer\installer.iss
# → build\bin\Switchy_Installer.exe
```

## darwin/

The `darwin/` directory contains macOS plist files generated by Wails. Switchy is a **Windows-only** application — these files are not used and exist solely because Wails scaffolds them.
